# Memory

Stable facts about this domain (component C3 of Harness²). The file is loop-owned. A fact that is true for one task only does not go here.

Format of each line: `- <fact> {fact ✓YYYY-MM-DD <decay>; <method>}` or `- <claim> {hypothesis}`. Decay classes: fast = 30 days, medium = 6 months, slow = 3 years.
