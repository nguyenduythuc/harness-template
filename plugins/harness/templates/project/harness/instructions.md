# Instructions

These are the working instructions of the executor. The file is loop-owned: the improvement loop proposes changes to it, and a change goes into `main` only through an h0-promotion PR.

## How to do a task

1. Read the task and the files that it names.
2. Find the code that the task changes. Read it before you edit it.
3. Make the smallest change that does the task.
4. Run the checks of the project: typecheck, lint and test.
5. Read the output of each check. Fix each failure that your change caused.
6. Write a short summary: what you changed, and which checks passed.
